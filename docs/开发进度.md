## 下次从这里开始

1. 在 .env 填写 DEEPSEEK_API_KEY，按 README 启动本地前后端。
2. 注册测试账号，上传默认样图。追问检测结果，再导入一份 Markdown 并确认发布。检查回答的引用能否定位到原文。
3. 需要验证语义检索时配置独立 Embedding 接口，在独立测试库用同一文档及同一组问题比较关键词、向量与混合检索。通过 RETRIEVAL_MODE=keyword、vector、hybrid 切换（重启后端）。
4. 启动 Docker 引擎后运行 Compose，检查 Linux 推理、知识确认中断后恢复、重启后会话和偏好及文件保留情况。

六张 HIT-UAV 图片在当前 Windows CPU 环境的框数按文件名排序为 12、9、1、1、16、3。只有默认图在原仓库有可逐框比较的历史标签。获取其余图的独立对照基线后再验收跨平台数值误差。
