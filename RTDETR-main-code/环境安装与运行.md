## 2. 创建并激活环境

如果已经创建 `infrared-agent` 环境，跳过创建命令。

```powershell
conda create -n infrared-agent python=3.11 -y
conda activate infrared-agent
python --version
python -c "import sys; print(sys.executable)"
```

确认输出为 Python 3.11，解释器路径包含 `envs\infrared-agent`。原来的 Python 3.8 环境可以继续保留作为对比基线。

```powershell
python -m pip install --upgrade pip -i https://mirrors.aliyun.com/pypi/simple/ --timeout 120
cd D:\code\Git\infrared-agent\RTDETR-main-code
```

如果项目放在其他位置，请调整 `cd` 路径。

## 3. 安装 CPU 版 PyTorch

以下直链对应 **Windows x64、Python 3.11**，`cp311` 表示 Python 版本。不要用于 Python 3.8 或 Linux 容器。

```powershell
python -m pip install "https://mirrors.aliyun.com/pytorch-wheels/cpu/torch-2.0.1%2Bcpu-cp311-cp311-win_amd64.whl" -i https://mirrors.aliyun.com/pypi/simple/ --timeout 120
```

```powershell
python -m pip install "https://mirrors.aliyun.com/pytorch-wheels/cpu/torchvision-0.15.2%2Bcpu-cp311-cp311-win_amd64.whl" -i https://mirrors.aliyun.com/pypi/simple/ --timeout 120
```

上述镜像文件地址在验证当天可访问，下载速度取决于网络。若镜像失效，可使用官方 CPU 源：

```powershell
python -m pip install torch==2.0.1 torchvision==0.15.2 --index-url https://download.pytorch.org/whl/cpu --timeout 120
```

参考：[PyTorch 官方历史版本安装说明](https://docs.pytorch.org/get-started/previous-versions/)。本项目的 CPU 推理无需安装 CUDA。

## 4. 安装基础及扩展依赖

先确认当前目录包含 `requirements.txt`。

```powershell
python -m pip install -r requirements.txt numpy==1.26.4 opencv-python==4.8.1.78 torch==2.0.1+cpu torchvision==0.15.2+cpu -i https://mirrors.aliyun.com/pypi/simple/ --timeout 120
```

再安装自定义源码需要的扩展依赖，使用本机已验证的版本：


## 7. 已应用的 Python 3.11 兼容性修复

旧检查点包含小波卷积的序列化闭包及 lambda。迁移到 Python 3.11 时，曾在 `wt_function` 调用处出现 `SystemError: unknown opcode`。当前源码已在 `ultralytics/nn/extra_modules/wtconv2d.py` 的 `forward()` 中改为直接调用当前解释器下的实现：

```python
curr_x = WaveletTransform.apply(curr_x_ll, self.wt_filter)
next_x_ll = InverseWaveletTransform.apply(curr_x, self.iwt_filter)
```

步长处理也已改为直接调用：

```python
if self.stride > 1:
    x = F.conv2d(
        x,
        self.stride_filter.to(x.device),
        bias=None,
        stride=self.stride,
        groups=self.in_channels,
    )
```

这些修改没有覆盖或重新训练 `best.pt`。使用当前源码时无需再次修改。不要用旧源码覆盖该文件，否则可能重新引入错误。

已验证的范围：上述单张测试图片在 Python 3.11 下预测成功，得到 4 个 Car 和 12 个 Bicycle；与先前 Python 3.8 保存的标签相比，类别、框坐标和置信度在导出文本精度下完全一致。尚未据此证明全部图片、GPU 或 Linux 部署均已通过验证。

## 8. 常见问题

### 找不到 cv2 或其他模块

先确认激活了正确环境，并完整执行第 4 节。导入名 `cv2` 对应安装包 OpenCV，不要安装名为 `cv2` 的包。

### 找不到 requirements.txt

进入 `RTDETR-main-code` 目录后重新执行。项目根目录不是该文件所在位置。

### 下载仍然来自 PyTorch 官方源

普通 PyPI 镜像不一定托管 `+cpu` 安装包。`--extra-index-url` 并不意味着所有包都走国内源。第 3 节使用阿里云 wheel 直链，可明确下载来源。

### 误设置了本地代理

如果曾设置错误的临时代理，在当前 PowerShell 清除：

```powershell
Remove-Item Env:HTTP_PROXY -ErrorAction SilentlyContinue
Remove-Item Env:HTTPS_PROXY -ErrorAction SilentlyContinue
```

### 再次出现 unknown opcode

检查实际加载的源码路径和第 7 节修复是否存在。若报错落在其他函数，需要根据完整堆栈检查对应序列化函数；重复安装依赖或反复运行通常无法解决这一类问题。

### 出现 OpenMP 重复加载错误

先核对是否误用了 Anaconda base 或混入其他环境。此前该错误发生在默认 base 环境，不应通过全局设置 `KMP_DUPLICATE_LIB_OK` 掩盖新环境的问题。
